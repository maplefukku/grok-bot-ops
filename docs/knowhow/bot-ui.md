# bot-ui

ボットと双方向にやり取りする専用 UI。

## /Make Bot UI

- 内容: ボットに専用の操作画面を作らせられる。画面上の操作ごとにボットへメッセージが飛び、裏でエージェント処理を走らせられる。例: メールを Instagram 風にスワイプし、スワイプごとに DM 下書きや Slack 共有を実行。

## botvillage（複数ボットの可視化）

- 内容: 複数ボットの JSONL ログを島/街マップで可視化し、ボットが働く様子を見せる大型プロンプトが公開されている。webhook routine、Tailscale での公開、プレイヤーキャラから村人ボットに話しかける UI、という仕様まで含む。

- 内容: 「人が触るフロントをボットに作らせ、裏でエージェントを動かす」が基本形。UI は成果物ではなく、ボットへの入力装置として設計する。
