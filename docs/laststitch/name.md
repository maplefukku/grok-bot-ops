# 表示名と handle

LOCK。表示名にカタカナは 0。数字の文字数上限は、公式ページに書いてあるものだけ使う。ボットは Instagram にログインしない。

関連: [bio.md](./bio.md) · [meta-taps.md](./meta-taps.md) · [account.md](./account.md) · [schema.md](./schema.md)

## 表示名（入力する文字列）

第一候補（そのまま試す）:

`最後の一針 / LAST STITCH LAB`

入りきらなければ（溢れ規則）:

- 名前欄: `最後の一針`
- bio の先頭: `LAST STITCH LAB`（本文は [bio.md](./bio.md)）

名前欄の文字数上限は、取得した公式ページに数字が無い。数字を発明しない。画面が拒否したら第二候補へ。表示名にカタカナを足さない。

プロフィールの名前は、公式どおり Edit profile または Accounts Centre の Profiles から更新する。

## handle

1. 第一: `@laststitch.lab`（`.lab` をそのまま試す）
2. Instagram が拒否したら: `@laststitchlab`

公式ヘルプは、使いたい username が既にあるとき、periods, numbers, underscores or abbreviations を足せると書いている。ピリオドは username の文字として公式に言及されている。これを法解釈しない。弾かれたら fallback するだけ。

- 出典: https://www.facebook.com/help/instagram/513717858639392 （取得: 2026-08-31）
- 出典: https://help.instagram.com/513717858639392 （取得: 2026-08-31）

確定した username は [account.md](./account.md) に書き戻す。

## FLAG（判断しない）

Terms に「You can't use a domain name or URL in your username without our prior written consent.」がある。`@laststitch.lab` がこれに当たるかは書かない。試して拒否されたら `@laststitchlab`。
