## handle

1. 第一: `@laststitch.lab`（`.lab` をそのまま試す）
2. Instagram が拒否したら: `@laststitchlab`

公式ヘルプは、使いたい username が既にあるとき、full stops、numbers、underscores、abbreviations を足せると書いている。full stops はピリオド。これを法解釈しない。弾かれたら fallback するだけ。
